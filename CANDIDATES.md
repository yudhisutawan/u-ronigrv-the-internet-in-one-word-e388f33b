# Kandidat Lokal — The Internet in One Word

Kriteria juri (sesuai urutan di RULES.txt / competition.yaml):
1. Satu kata yang mendeskripsikan SELURUH internet.
2. Lucu dengan sendirinya, tanpa penjelasan.
3. Benar tentang internet secara keseluruhan (bukan satu aplikasi/situs/mood).
4. Mengejutkan — bukan kata pertama yang terlintas.
5. Langsung kena dalam satu ketukan: ejaan benar, langsung terbaca, pendek.

Ideal juri: "The best word makes a reader laugh and then nod" — ketawa dulu, lalu mengangguk.

## Pool brainstorm yang tidak masuk turnamen (alasan singkat)

- Dumpsterfire (12) — lucu dan benar, tapi klise + terlalu panjang.
- Chaos / Wild / Crazy / Addictive / Madness / Insanity — kata pertama yang terlintas; gagal kriteria 4.
- Memes / Doomscroll / Cringe / Clickbait — hanya satu bagian/mood internet; gagal kriteria 3.
- Kerfuffle / Brouhaha / Hullabaloo — kata yang sangat lucu, tapi terlalu panjang (8–10) dan hanya berarti "keributan kecil".
- Panopticon / Hallucination / Pigeonhole (Hermes) — pintar tapi tidak lucu; gagal kriteria 2.
- Swamp / Sewer / Landfill / Sludge — lucu dan benar, tapi kalah lawan Slop di bunyi, kebaruan, dan panjang.
- Glitch / Buffering / Jenga / Hydra / Limbo / Cult / Grift / Ponzi / Racket / Bluff / Bananas / Bonkers / Ruckus / Feral — semua kuat, tapi kalah pairwise lawan pemenang (lihat TOURNAMENT.md, bagian cross-check).
- 404 / Bit / TLDR / FOMO — bukan kata utuh / butuh pengetahuan kode; berisiko di kriteria 1 dan 5.
- Porn / Shitshow / Clusterfuck — shock demi shock; rules bilang shock itu tidak dihitung.
