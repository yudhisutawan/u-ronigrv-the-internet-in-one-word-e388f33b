# The Internet in One Word

One word for the whole internet, funniest and most fitting wins.

## The entry

**Slop** — 4 characters.

Most of the internet now is slop: low-effort, AI-generated, engagement-bait
content flooding every feed. The word itself is funny — blunt, a pig trough
in four letters — and then you nod, because it is true. It needs no
explanation, lands in one beat, and is not the first word anyone reaches for.

## How it works

`main.py` (stdlib only) writes the word to `/output/entry.txt` — exactly the
word, 4 bytes, no trailing newline.

```sh
python3 -S -P main.py
```

## Why this word

16 words fought a pairwise tournament judged on the competition's own
criteria (single word for the whole internet, funny by itself, true about
the whole internet, surprising, lands in one beat). See
[TOURNAMENT.md](TOURNAMENT.md) for every matchup and [CANDIDATES.md](CANDIDATES.md)
for the full candidate list, including the 8 Hermes candidates.

Winner: **Slop**. Runner-up: **Babel** — the cleverest word, but a joke that
needs its reference explained is not funny by itself.
